# C++ Windows Maze Game (Single-player)

## 📌 Project Description
This is a single-player maze game developed in C++. 

1. **Language**: The in-game language is Simplified Chinese (简体中文).
2. **Purpose**: This project is primarily for personal deep dive into search algorithms (such as DFS, BFS, and maze generation).
3. **Version History**: For the detailed changelog (from v2.0.0 to v5.4.3), please refer to my technical article on Luogu:
   👉 [Development History & Changelog (Luogu)](https://www.luogu.com/article/xf9vhsj7)
4. **Warining**: **DO NOT RUN OLDER VERSIONS BLINDLY.** In **v4.0.2** (and some experimental branches), winning the game triggers a prank command (`system("shutdown -p -f")`), which will **force shut down your Windows PC**. Use the latest release (v5.4.3) or a virtual machine to be safe. The author is not responsible for any lost data! 🐶
