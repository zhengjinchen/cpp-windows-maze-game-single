# C++ Windows Maze Game (Single-player)

## 📌 Project Description
This is a single-player maze game developed in C++. 

1. **Language**: The in-game language is Simplified Chinese (简体中文).
2. **Purpose**: This project is primarily for personal deep dive into search algorithms (such as DFS, BFS, and maze generation).
3. **Version History**: For the detailed changelog (from v2.0.0 to v5.4.3), please refer to my technical article on Luogu:
